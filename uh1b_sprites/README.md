# UH-1B 휴이 도트 작업 폴더 (진행 중, 게임 반영 전)

로드맵 5번 보스(UH-1B·AH-1G 쌍둥이)의 휴이 쪽이에요. 코브라(`ah1g_sprites/`)와 같은 도구(`px.py`)와 같은 축척을 써요.

- 축척: 아파치 동체 기준 21.94px/m(2x). UH-1B 동체 12.08m(39'7.5")가 약 265px, 메인 로터 13.41m가 252px, 꼬리 로터 2.59m가 54px이에요.
- 참고 그림: `ref/uh1b_side_render.webp` (사용자가 준 측면 렌더, 오른쪽을 봐서 뒤집어 씀).
- 방식: 윤곽은 렌더 위 픽셀 좌표로 직접 땄고(`geom_huey.py`), 칸 안의 명암과 칠(노랑 띠, 빨간 줄)은 렌더에서 칸마다 평균색을 뽑아 재질 안에서 순위로 램프에 대응시켰어요. 렌더의 먼지와 반사가 위장 무늬처럼 보이지 않게 기본 원통 명암과 반씩 섞었어요. 글씨는 뒤집히면 거울 글자가 되니까 스텐실 레이어(`MarksL/R`)로 따로 그려요.
- 레이어: 동체(`HueyBoss`), 유리, 스텐실 좌·우, M5 기수 포탑(방수포 포함), 옆 로켓 포드, 메인 로터 6프레임(스태빌라이저 바 포함)과 블러, 꼬리 로터(빨강·흰색 날끝)와 블러, 좌표 json.
- 실행: `python3 build_huey.py`, 미리보기 `python3 preview_huey.py`, 호버 GIF(두 기체, 로터와 항법등) `python3 anim_idle.py`. 결과는 `out/`에 생기고 커밋하지 않아요.
