# AH-1G 코브라 도트 작업 폴더 (진행 중, 게임 반영 전)

로드맵 5번 보스(UH-1B·AH-1G 쌍둥이)의 코브라 도트 작업이에요. 아직 사용자 허락을 받은 그림이 없어서, 여기에는 생성 도구와 참고 그림만 올려 둬요. 만든 PNG는 `out/`에 생기고 커밋하지 않아요(`.gitignore`).

## 축척

- 아파치 동체 기준이에요. `ApacheBoss.png` 동체가 330px이고 AH-64 동체 길이가 15.04m라서 21.94px/m(2x), 1x로는 10.97칸/m예요.
- 코브라 동체(기수에서 꼬리날개 끝까지 44'5.2" = 13.54m)는 약 297px이에요.
- 메인 로터는 아파치 로터 규칙을 따라요. 아파치 로터가 14.63m에 274px이니까, 코브라 로터(13.41m)는 252px이에요.
- 꼬리 로터도 아파치 꼬리 로터(2.79m에 58px) 기준이라 2.59m가 54px이에요.

## 파일

| 파일 | 내용 |
|---|---|
| `ref/ah1g_bell_ga_209900-9.webp` | Bell 치수 도면. 형상 기준이에요 (90.04px/m, 스캔이 0.5도 돌아가 있어서 보정함) |
| `ref/ah1g_color_profile.png` | 컬러 프로필 (녹색 위장, 상어 입) |
| `ref/ah1g_line_3view.png` | 양산형 선화 (흡입구, 나셀, 패널선) |
| `refs.py` | 세 그림을 같은 좌표(기수 끝에서 뒤로 m, 스키드 바닥에서 위로 m)에 맞추는 등록 코드 |
| `px.py` | 칸 단위 도트 도구 (다각형 커버리지, 레이어, 외곽선, 2x 내보내기) |
| `geom.py` | 치수 도면에서 칸 단위로 읽은 윤곽 좌표 |
| `build_cobra.py` | 레이어 생성기 (동체, 캐노피, 포탑, 포신, 포드, 로터, 데칼, 좌표 json) |
| `preview.py`, `zoomgrid.py` | 아파치와 같은 축척 비교 그림, 칸 격자 확대 그림 |

## 지금 상태와 다음 할 일

- 1차 시안: 치수 도면 좌표로 형상을 잡고, 컬러 프로필과 선화에서 양산형 디테일(흡입구, 나셀, 배기구, 패널선, 상어 입)을 가져왔어요. `python3 preview.py`로 `out/`에 레이어와 비교 그림이 생겨요.
- **포탑:** 사용자가 준 포탑 사진 기준이에요. 턱 밑이 사각으로 파여 있고(홈 안쪽은 어둡게, 뒷벽 모서리는 밝게), 그 안에 **뚜껑 달린 네모 드럼 포탑**(모서리만 둥근 사각)이 매달려요. 포신은 M129 40mm이고 앞면 위쪽 슬롯에서 아주 짧게 나와요. 공 모양 돔, 상자형 하우징에 긴 미니건은 둘 다 거부됐어요. (사막 위장 프로필은 포탑 모양 참고용이었어요.)
- 세분화(레이어 분리): 동체, 캐노피 유리, 상어 입, 스텐실(좌우), 턱 포탑, 포신(평상시와 반동 2프레임), 안쪽·바깥 포드, 메인 로터 6프레임과 블러, 꼬리 로터와 블러를 따로 뽑아요.
- 그림은 미리보기로 사용자 허락을 받은 다음에 게임 쪽에 넣어요.
